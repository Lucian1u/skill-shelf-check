边界

这个工具只提供需要人工复核的信号。它不会：

  • 联网
  • 上传文件
  • 修改文件
  • 删除 Skill
  • 自动修复
  • 读取 Agent 日志
  • 判断内容事实是否过时
  • 做安全扫描
  • 承诺支持所有 Agent / Skill 语法
